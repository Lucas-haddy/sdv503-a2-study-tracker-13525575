# sdv503-a2-study-tracker-13525575

The repository for Assessment 2 of SDV503, where I will create a command-line study tracker.

## Instructions

1. Open the terminal window and type `node app.js` to start the tracker.
2. When prompted, enter the subject you wish to record.
3. When prompted, enter the duration (in minutes and hours) of your study that you wish to record.
4. If you wish to enter another study session type `yes or y` when prompted and repeat steps 2-3.
5. If you are finished entering study sessions type `no or n` when prompted, you should see the total study time appear.
6. When prompted type `yes` or `no` if you would or would not like to see all sessions recorded by the tracker.
7. After choosing the system should automatically exit.
